# Агент: план недели и корзина ВкусВилла

Веб-приложение планирует неделю и показывает список покупок. Собрать **реальную корзину** в магазине оно не может: ссылку на корзину создаёт только ВкусВилл MCP. Эту часть делает агент — Claude с подключённым MCP и skill-файлом [`SKILL.md`](SKILL.md).

## Что делает агент

1. Спрашивает только то, что меняет план: параметры, цель, что не ест, технику, время на рецепт, дни готовки и приёмы пищи вне дома, любимые блюда, бюджет. Если приложить экспорт из приложения (Профиль → Экспорт), берёт всё оттуда.
2. Считает норму и объясняет расчёт.
3. Собирает неделю: готовка на 2 дня, завтраки блоками, порции под норму ±100 ккал, клетчатка ~30 г.
4. Ищет товары и рецепты во ВкусВилле (`vkusvill_recipes`, `vkusvill_products_search`, `vkusvill_product_details`).
5. Делает **две** ссылки на корзину (`vkusvill_cart_link_create`): основную на выходные и отдельную с сырым мясом — ко дню перед второй готовкой.

## Как подключить

### Claude Code

1. Добавьте MCP-сервер ВкусВилла:

   ```bash
   claude mcp add --transport http vkusvill https://mcp.vkusvill.ru/mcp
   ```

   Поиск товаров и рецептов работает без авторизации. Персональные функции (наличие, история заказов) требуют OAuth: зарегистрируйте агента на https://vkusvill.ru/oauth/registration/ — `client_id` и `client_secret` придут на почту.

2. Подключите skill:

   ```bash
   mkdir -p ~/.claude/skills/meal-prep-cart && cp agent/SKILL.md ~/.claude/skills/meal-prep-cart/SKILL.md
   ```

3. Напишите в Claude Code: «Собери план питания на неделю и корзину во ВкусВилле».

### claude.ai

Подключите коннектор ВкусВилла в настройках Connectors, создайте skill из `SKILL.md` и попросите то же самое.

## Почему так

- **Две корзины.** Сырое мясо хранится 1–2 дня. Если готовка во вторник и в четверг, фарш на четверг, купленный в субботу, к четвергу испортится.
- **Фрукты не в корзине.** Люди выбирают их сами — это выяснилось на первом же реальном пользователе.
- **Сначала любимые блюда.** Рецепты из базы — для разнообразия; план из незнакомых блюд не доживает до среды.

Адрес MCP-сервера и названия инструментов — по состоянию на октябрь 2026; если ВкусВилл их поменяет, поправьте `SKILL.md`.
