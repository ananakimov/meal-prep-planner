# Дизайн-система

Основа — дизайн-система мобильных прототипов автора: светлый серо-голубой фон, белые карточки, один синий акцент, шрифт Onest. Токены лежат в [`src/index.css`](../src/index.css), компоненты — в [`src/components/ui.tsx`](../src/components/ui.tsx).

## Токены

Все цвета — HSL в `:root`, зарегистрированы в [`tailwind.config.ts`](../tailwind.config.ts).

| Группа | Токены | Где используется |
| --- | --- | --- |
| Поверхности | `background`, `card`, `foreground` | фон страницы, белые карточки, текст |
| Бренд | `primary`, `primary-soft`, `link` | основные кнопки, активная вкладка, ссылки и иконки |
| Вторичные | `secondary`, `muted`, `muted-foreground`, `border` | неактивные чипы, подписи, разделители |
| Макросы | `c-sky` белок · `c-amber` жиры · `c-lime` углеводы · `c-lilac` клетчатка · `c-pink` сладкое | точки и полосы КБЖУ |
| Плитки | `tile-sky`, `tile-lilac`, `tile-rose` | плитки-напоминания на экране «Сегодня», по порядку |
| Тени | `shadow-card`, `shadow-soft` | карточки; поднятые элементы и активный чип |

Радиус `--radius: 1rem`; карточки `rounded-[20px]`, плитки `rounded-[1.75rem]`, кнопки — `rounded-full`.

## Компоненты

- **AppShell** — `max-w-md` по центру, `pb-28` под таббар.
- **TabBar** — 4 вкладки (Сегодня · Неделя · Покупки · Профиль), без капсул; активная иконка цвета `link` и толще. Скрыт в онбординге, на рецепте и в «Съел другое».
- **TabHeader / ScreenHeader** — заголовок корневой вкладки `text-2xl font-extrabold` без стрелки; внутренний экран со стрелкой «назад» цвета `link` без подложки.
- **Block** — белый блок, заголовок внутри `text-[22px] font-bold`, одного размера на всех экранах.
- **Tile** — пастельная плитка-вход: белый квадрат с иконкой, заголовок, подпись, шеврон.
- **Chip** — фильтр-капсула; активный — `primary-soft` с тенью, неактивный — `secondary`.
- **MacroLine / MacroBars** — КБЖУ строкой с цветными точками и полосами план/факт.
- **RecipeCard** — квадратная карточка в горизонтальной ленте (2 целых + край третьей). Без фото — светлая заливка, а не градиент с иконкой.
- Кнопки: основная `btn-primary` (заливка primary), вторичная `btn-secondary`. Чёрных кнопок нет.

## Правила

- Выделение карточки — `outline`, не `ring`: `shadow-card` затирает ring.
- Лента внутри блока: `-mr-4 pr-4` и `overflow-hidden` у блока.
- Тексты простым языком, без придуманных цифр. Цифры КБЖУ — из рецептов и расчёта.
- Вибрация `tapLight()` на нажатиях (`src/lib/haptics.ts`).
